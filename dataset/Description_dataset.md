# Описание датасета

## Файлы


| Файл        | Записей | Описание                    |
| ----------- | ------- | --------------------------- |
| `train.csv` | 800     | Обучающая выборка с метками |
| `val.csv`   | 200     | Валидационная выборка с метками |
| `test.csv`  | 200     | Тестовая выборка без меток* |


## Поля CSV


| Поле    | Тип | Описание                |
| ------- | --- | ----------------------- |
| `id`    | int | Уникальный идентификатор |
| `text`  | str | Текст сообщения, возможны переносы строк |
| `label` | str | `order` или `not_order` |


## Класс `order`

Оформленный заказ для переноса в таблицу. Типичная структура:

```
заказ <номер>
<имя покупателя>
<товар> - <количество>
```

Допускаются вариации: флаги стран, цены в строке, пометки «самовывоз» / «срочно», несколько товаров.

**Важно:** часть заказов имеет нестандартное оформление (префиксы, `заказ №`, корпоративные пометки) — модель должна обобщать, а не запоминать одно правило.

## Класс `not_order`

Всё, что не является готовым заказом:

- вопросы о наличии и цене («есть iPhone 15 Pro?»);
- отмены и уточнения («заказ 3301 — отмена»);
- служебные сообщения, обсуждения, рекламы и тд;
- неполные сообщения без корректного формата заказа;

## Split


| Split | ID        | order | not_order |
| ----- | --------- | ----- | --------- |
| train | 1–800     | 400   | 400       |
| val   | 801–1000  | 100   | 100       |
| test  | 1001–1200 | 100   | 100       |


Метки test хранятся у меня для проверки.

## Важно для обучения

1. **Не используй** `test.csv` **для обучения или подбора параметров.**
2. Читай CSV через `csv` / `pandas` — тексты multiline в кавычках.
3. Простой regex **не решает** задачу полностью — нужна ML-модель.
