# Проект: Классификация текстовых заказов (Order Classification AI)

Система на базе трансформера для бинарной классификации текстов на русском языке. Модель определяет, является ли входящее текстовое сообщение заказом (`order`) или нет (`not_order`).

---

## 📦 Установка зависимостей и окружения

Вы можете использовать как стандартный инструментарий Python, так и современный быстрый менеджер пакетов `uv`.

### Вариант 1: Через стандартный pip
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Вариант 2: Через менеджер пакетов uv (Рекомендуется)
```bash
uv venv
source .venv/bin/activate
uv sync
```

---

## 🚀 Запуск обучения модели

Скрипт запускает автоматический пайплайн: загружает данные, рассчитывает базовый ML-бейслайн для сравнения, дообучает нейросеть и сохраняет финальные веса.

```bash
python3 -m src.inference.train
```

---

## 🔮 Запуск инференса (Прогнозирование)

Модель поддерживает два режима работы: классификацию одиночной строки из консоли и массовую пакетную (батчевую) обработку CSV-файлов.

### 1. Предсказание для одного текста
```bash
python3 -m src.inference.predict --text "заказ 1042\nИван Петров\niPhone 15 Pro - 2"
```

### 2. Пакетная обработка CSV-файла
```bash
python3 -m src.inference.predict --input data/test.csv --output submissions/test_predictions.csv
```

## 📊 Метрики и результаты экспериментов

* **Детальные отчеты:** Метрики валидации для экспериментов с разным количеством эпох автоматически фиксируются в директории `reports/`. 
* **Управление генерацией:** Создание отчетов происходит автоматически при каждом обучении. При необходимости этот шаг можно отключить, изменив флаг оценки в файле конфигурации `config.py`.
* **Финальные предсказания:** Таблица результатов работы модели на тестовых данных сохраняется по пути: `submissions/test_predictions.csv`.

## 📝 Выводы по проекту

1. **Успешное дообучение:** Реализован полный пайплайн от загрузки данных до генерации артефактов. Модель успешно дообучена на базе архитектуры `RuBERT` и генерирует предсказания в строгом соответствии с форматом ТЗ.
2. **Влияние гиперпараметров:** Экспериментально доказано, что итоговое качество классификации критически зависит от количества эпох обучения (увеличение числа эпох позволило нейросети уверенно превзойти TF-IDF бейслайн).
3. **Характер ошибок (Безопасный скоринг):** Модель демонстрирует идеальный показатель **Precision (1.0000)**. Ошибки классификации носят исключительно характер *False Positive* (когда не-заказ помечается как заказ). Модель полностью исключает ошибки типа *False Negative* (пропуск реального заказа), что является критически важным для бизнес-логики проекта, так как минимизирует упущенную прибыль.
